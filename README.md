# iCloud Export

Утилита для macOS (и Linux x86_64): выгружает файлы из альбомов iCloud Photos (включая «Скрытые» и «Недавно удалённые»)
в исходном качестве. Если фото отредактировано, сохраняется версия с правками. Метаданные из iCloud
(дата, место, подпись, избранное, альбомы) записываются в файлы, дата создания и дата изменения файла
выставляются по дате съёмки. При повторном запуске в ту же папку скачивается только новое.

Файлы называются `2024-06-10 21.30.05 IMG_1234.HEIC`: дата и время съёмки, затем исходное имя.
Поэтому по имени файлы сортируются в порядке съёмки, а одинаковые `IMG_…` с разных устройств
не пересекаются. Если всё же совпало (то же имя в ту же секунду), добавляется `_2`.
Поддерживаются личная и общая медиатека (iCloud Shared Photo Library).

## Сборка

Нужен только Docker:

    make app        # → dist/icloud-export.app
    make test       # тесты в контейнере
    make test-darwin  # тесты, которые проверяют birthtime и exiftool на этом Mac

## Linux x86_64

    make linux      # → dist/icloud-export-linux-amd64 (статический бинарник)

Собственного окна нет: если есть графика, интерфейс открывается в браузере (`xdg-open`), иначе
адрес печатается в терминал. Сервер слушает только `127.0.0.1`. На сервере без экрана задайте
порт и пробросьте его по SSH-туннелю:

    icloud-export-linux-amd64 -addr 127.0.0.1:8765
    ssh -L 8765:127.0.0.1:8765 user@server   # на своей машине, затем ссылка из терминала

На Linux дата создания файла не выставляется (ядро этого не позволяет), только дата изменения.
exiftool ставится пакетом: `apt install libimage-exiftool-perl` / `dnf install perl-Image-ExifTool`.
Сессия хранится в `~/.config/icloud-export/`, журнал — в `~/.local/state/icloud-export/`.

## Запуск (macOS)

- `dist/icloud-export.app` — двойной клик.
- `dist/icloud-export probe` — проверка входа и доступа к альбомам из терминала.
- `dist/icloud-export -browser` — интерфейс в браузере вместо отдельного окна.

Для входа нужен основной пароль Apple ID и код 2FA (пароли приложений iCloud Photos не принимает).
Пароль на диск не сохраняется. Сессия хранится в `~/Library/Application Support/icloud-export/session.json`.

Метаданные пишутся внутрь файлов через `exiftool`, если он установлен (`brew install exiftool`
или кнопкой в интерфейсе). Без `exiftool` они сохраняются в сайдкары `*.xmp` рядом с файлами.

В папке выгрузки появляются служебные файлы: `.icloud-export.json` — индекс для докачки,
`.icloud-export-errors.log` — журнал ошибок.
